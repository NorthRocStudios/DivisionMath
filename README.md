# DivisionMath

A cross-platform math library for CPU and GPU that uses the same code everywhere.

## Overview

This is built for a future library, DivisionTranslate. These two libraries together will replace ComputeSharp to allow for cross-platform builds of DivisionEngine! Additionally, unlike ComputeSharp, DivisionMath allows for 1-1 parity math operations on the CPU and GPU (with DivisionTranslate).

## Features

- Same API on CPU and GPU
- Full swizzling support (`.xyz`, `.rgb`, `.xy`, etc.)
- No external dependencies
- MIT licensed
